# SBOM-style accepted-ISO receipts.
#
# Each entry records one NCZ installer ISO whose build inputs, install-phase
# outcome, and boot-phase outcome are KNOWN. The Makefile's SUBSTRATE_SHA pin
# tells you WHICH d-i netinst went into the build. This file tells you
# whether that build's INSTALLER actually completed in QEMU/AAVMF and whether
# the INSTALLED SYSTEM reached userspace. The two are different observations
# and the prior comments above SUBSTRATE_SHA conflated them.
#
# Format per entry:
#   # iso_path|<bytes>|<sha256>|<substrate_sha256>|<build_date_utc>
#   #   install_phase: <one of pass | fail | not-run>
#   #   boot_phase:    <one of pass | fail-missing-gpt | fail-no-banner |
#   #                          fail-no-userspace | fail-timeout | not-run>
#   #   receipt_doc:   <path-to-doc-with-raw-evidence>
#   #   harness:       <gate-script-and-rev-if-known>
#   #   notes:         <free text, esp. what was NOT validated>
#
# The receipt is a CLAIM, not an end-to-end gate. "not-run" is honest: it
# means we have not yet qualified that image, not that the image is broken.
