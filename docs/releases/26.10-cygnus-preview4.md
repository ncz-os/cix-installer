# NCZ-OS 26.10 "Cygnus" — Preview 4

Preview 4 uses Debian Testing (Forky) and includes Desktop and Magnetar Server
images for amd64 and arm64. The 2026-11-19 build is `2026.11.19-4b51adc1`.

All four images use a Linux 7.4.0-rc3 release candidate kernel. Back up your
data before installing.

## Screenshots

![NCZ-OS 26.10 Cygnus desktop](https://gitlab.com/ncz-os/cix-installer/-/raw/main/docs/screenshots/26.10/00-hero.jpg)

## One kernel line: Linux 7.4

NCZ-OS now uses the Linux 7.4 kernel line only, on both architectures:

- **amd64:** `7.4.0-rc3-t2-ncz` (package `7.4.0-rc3-4`). One kernel serves Apple T2 MacBooks and generic Intel/AMD PCs alike.
- **arm64 (CIX Sky1):** `7.4.0-rc3-sky1-ncz` (+r303).

*Update, 2026-11-22:* NCZ-OS provides both kernel lines from the next preview: 7.4 is the default on the desktop and 7.3 (7.3.5 and later) is the default on the server and the recovery kernel. Preview 4 itself is unchanged. See [the design rationale, section 8.3](../DESIGN-RATIONALE.md#83-why-there-are-two-kernel-lines).

## What's new

- Desktop includes the 2026-11-18 Singularity snapshot with the NCZ-OS patch set,
  NCZ Screensavers 0.8.22 and settings plugin 0.3.27.
- Magnetar Server installs headless with a text console and SSH on port 22.
  A colour ASCII black hole screensaver starts on the console after 180 seconds
  idle.
- The lock-screen Black Hole screensaver no longer shows one magnified corner of
  the picture when the GPU gets warm (NCZ Screensavers 0.8.22).

## Installing

Each image has its own section below with direct download links for every
file you need. The same files are on the GitHub and the GitLab release pages.

| arm64 | server | `ncz-os-arm64-20261119-4b51adc1-server.img` | 958398464 | `61dd0b39e5d4262ba3806ba48e2cfe3516e2d6be70d7b86d71f928862f773302` |

Each image is compressed with zstd and split into parts under 2 GiB.
Download the parts, both checksum files for your chosen image and
[`ncz-join-image.sh`](https://gitlab.com/ncz-os/cix-installer/-/releases/permalink/latest/downloads/ncz-join-image.sh) into one folder.
Run the join command for that image. It checks the parts, unpacks them and
checks the resulting raw image.

Write the `.img` to a USB drive of at least 16 GB. This erases the USB drive.
Boot from it and check the target disk before confirming. The installer
erases that disk.

Magnetar Server is the online flavour. Installation requires a wired network connection. The installer
downloads the system payload and verifies its SHA-256 before installing it.

## How this preview was checked

The following checks used build `2026.11.19-4b51adc1` on 2026-11-20.

- **Radxa Orion O6N (CIX Sky1), arm64 Server:** Full install and first boot
  completed with zero failed units. The NPU, Mali GPU and VPU drivers loaded
  and their device nodes were present. Boot entries were correct, including
  the rescue entry, and one kernel was installed.
- **Apple MacBookPro16,1 (T2), amd64 Server:** Running with zero failed units.
- **Apple MacBookPro16,1 (T2), amd64 Desktop:** Reached the desktop with zero failed units.
- **ASUS ROG Zephyrus M15 GU502LV (NVIDIA GeForce RTX 2060), amd64 Desktop:**
  Reached the desktop with zero failed units.
- Build `2026.11.19-4b51adc1` passed the automated virtual-machine install and boot check
  on both architectures: the desktop images with five sets of installer options and the installer screen check, and the server images with the server rescue-partition and offline-negative sets.

On an earlier Preview 4 build, arm64 Desktop reached the desktop on a CIX Sky1 board.

## Known issues

- With a USB drive attached at power-on, the login screen can appear about
  two minutes late on some systems. A fix is planned for a later preview.
- On Apple T2 MacBooks, the screensaver behind the lock screen runs at 15
  frames per second on purpose.
- The login banner can print twice on the text console. This is cosmetic.
  A fix is planned for a later preview.

## Not in this release

- Panthor is not shipped.
