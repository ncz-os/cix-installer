# NCZ-OS 26.10 "Cygnus" — Preview 1

> These notes describe the Preview 1 images of 2026-10-12 and are kept for reference. The current 26.10 images are described in [26.10-cygnus-20261013.md](26.10-cygnus-20261013.md).

First public preview of NCZ-OS 26.10 "Cygnus": a Debian-based desktop OS for **CIX Sky1 boards (arm64)** and **Intel/AMD PCs and Apple T2 Macs (amd64)**. Each image is a raw GPT disk image: write it to a drive of at least 16 GB (this erases the drive), boot it and follow the installer.

**Status: preview.** Both images are built on a release-candidate Linux kernel (7.3.0-rc7). Back up anything you care about.

**Download:** the Preview 1 images have been replaced; current images are on the [latest release](https://github.com/ncz-os/cix-installer/releases/latest) page. The Preview 1 source stays at tag [`v26.10-preview1`](https://gitlab.com/ncz-os/cix-installer/-/tree/v26.10-preview1).

| Image | Architecture | Kernel |
|---|---|---|
| `ncz-os-arm64-20261012-f64cba5` | arm64, CIX Sky1 | `7.3.0-rc7-sky1-ncz` |
| `ncz-os-amd64-20261012-07c0644` | amd64 (Intel/AMD PCs, Apple T2 Macs) | `7.3.0-rc7-t2-ncz` |

See [Supported GPUs and hardware](#supported-gpus-and-hardware) below for exactly what was tested.

## What's new
- **Desktop:** the Singularity desktop in the Cygnus theme (magenta and cyan on violet-black), with a first-login tour of the desktop, wallpapers, artist packs and the screensavers.
- **Lock screen over a live screensaver:** the lock screen sits on top of the running screensaver and does not ask for a password until you touch the keyboard or mouse. The saver drops to 8 fps at half resolution and freezes after 15 seconds to keep the machine cool.
- **Login screen matches the lock screen** (layout, spacing, field labels).
- **Screensavers:** NCZ Screensavers 0.8.12, 74 savers including the Black Hole, Magmasimplex and Fractasia showpieces, with performance tiers per GPU.
- **Sky1:** Linux 7.3.0-rc7 with the CIX GPU, VPU, NPU and audio drivers; Mali is the default GPU driver.
- **Apple T2 Macs:** a kernel with Apple T2 support, tested on MacBookPro16,1.
- **Boot menu:** rEFInd, with a rescue entry kept alongside the default.
- **One kernel per image:** the default, installer and rescue entries all boot the same 7.3.0-rc7 kernel; the 7.2 and "edge" kernel channels are gone ([`docs/ONE-KERNEL.md`](../ONE-KERNEL.md)).

## Supported GPUs and hardware
NCZ-OS Preview 1 ships drivers for **AMD, NVIDIA and Intel GPUs on amd64**, **Arm Mali on CIX Sky1 (vendor Mali stack by default, open Panthor driver also available)**, and the **CIX Sky1 NPU and VPU**. Machines we ran it on:

| Machine | CPU | GPU (driver) | Status on Preview 1 |
|---|---|---|---|
| Radxa Orion O6N | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| Minisforum MS-R1 | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| MacBookPro16,1 (two units) | Core i9-9980HK, Core i7-9750H | AMD Radeon Pro 5300M/5500M class (Navi 14, `amdgpu`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| ASUS ROG GU502LV laptop | Core i7-10750H | NVIDIA GeForce RTX 2060 Mobile (proprietary `nvidia`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| HP OmniDesk desktop | Core Ultra 7 265 | Intel integrated graphics (Xe-LPG, `i915`) | Installed, boots to desktop |
| Dell Inspiron 5521 (2013) | Core i7-3537U | Intel HD Graphics 4000 (`i915`) | Installed, runs the desktop |
| Mac mini 2011 (Macmini5,1) | Core i5-2415M | Intel HD Graphics 3000 (`i915`) | Installed, desktop works (hardware-accelerated graphics) |

Other GPUs and boards are untested. Video and audio playback and VPU hardware video decode were verified on the Sky1 boards; hardware video decode on other GPUs depends on the driver.

## Installing
**Easy way (Linux or macOS; needs `zstd`):**
1. Download [`ncz-join-image.sh`](../../tools/ncz-join-image.sh), `SHA256SUMS`, `PARTS.sha256` and all the `…img.zst.part-*` files for your architecture into one folder. (GitHub limits each file to 2 GiB, so each image is split.)
2. Run `sh ncz-join-image.sh arm64` (or `amd64`). It checks every part, joins and unpacks them, and checks the finished image. It never writes to a disk.
3. Write the resulting `.img` to a drive of at least 16 GB (this erases the drive), then boot it and follow the installer. Balena Etcher works on any OS; on Linux you can use `dd` (see the [README quick start](../../README.md#quick-start-install-on-hardware)).

**By hand:**
1. Check the parts: `sha256sum -c PARTS.sha256` (files you did not download report as missing; that is fine).
2. Join and unpack, for example for arm64: `cat ncz-os-arm64-20261012-f64cba5.img.zst.part-* | zstd -d -o ncz-os-arm64-20261012-f64cba5.img`
3. Check the image against `SHA256SUMS`: `sha256sum ncz-os-arm64-20261012-f64cba5.img`

Each image is 7.6 GB unpacked (about 5.7 GB compressed for arm64, 6.1 GB for amd64). Windows: use WSL, or unpack the parts with 7-Zip on the joined `.zst` file.

## Known limitations
- **Unplug USB serial / debug cables during the install.** The installer can mistake a USB-serial adapter for a braille display, which shows a "braille device?" prompt and squeezes the installer to the left of the screen. Answer *No*, or install with the cable removed.
- Preview quality: a release-candidate kernel and a new installer.
- Only the hardware listed above has been tested.
- **Apple T2 MacBooks run warm right after the first login:** the first-login tour is a one-minute CPU burst, and the discrete AMD GPU stays powered, so expect higher temperatures (about 60 °C idle) than on the other amd64 machines. A fix is planned for the next image.
- **Screensaver on the lock screen can fail to start at the default timing:** two idle-lock paths can race for the lock's saver connection, which leaves the lock screen up with no saver behind it (seen on one desktop PC; it did start on others). The lock itself always engages. A fix is planned for the next image.
- **Lock-screen screensaver on the T2 MacBooks:** automated checks could not confirm that the saver animates behind the lock screen on these two machines (it did on the others); under investigation.
- **Lock screen never blanks the display:** the "blank after N seconds" option is not implemented yet.
- **Resume on the T2 MacBooks:** suspend and resume work, but each resume logs a kernel warning and the Thunderbolt/USB4 controller is re-enumerated, so devices on those ports briefly disconnect.
- **Login screen on the T2 MacBooks:** the login screen runs at a different resolution from the desktop session, so its match with the lock screen is unverified on these machines.
- **File chooser on the Radxa Orion O6N:** the GTK file-chooser portal service can fail to start, so some apps may not be able to open a file-chooser dialog.

## In development (not in Preview 1)

These are being worked on for the next image and are **not** in the Preview 1
images:

- fixes for the known limitations above (T2 warm-up after first login, the lock-screen saver race);
- a lighter desktop profile for older, weaker machines;
- hardware capability tiers that pick sensible defaults per machine;
- a measured, per-machine screensaver pool chosen at first boot;
- a first-login tour slide about hardware video decoding in the NCZ Chromium build on Sky1.
