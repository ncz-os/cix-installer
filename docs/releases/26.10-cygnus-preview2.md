# NCZ-OS 26.10 "Cygnus" — Preview 2

NCZ-OS 26.10 "Cygnus" is a Debian-based desktop OS for **Intel/AMD PCs and Apple T2 Macs (amd64)** and **CIX Sky1 boards (arm64)**. Each image is a raw GPT disk image: write it to a USB drive of at least 16 GB (this erases the drive), boot from it and follow the installer.

**Status: preview.** Preview 2 (tag `v26.10-preview2`) replaces the 26.10 Preview 1 images of 2026-10-12 ([notes](26.10-cygnus-preview1.md)) and is published as a pre-release. Both images are built on the Linux 7.3.0-rc7 kernel, a release candidate. Back up anything you care about.

**Download:** the images are published on the project's [Releases page](https://github.com/ncz-os/cix-installer/releases) and on the [GitLab release page](https://gitlab.com/ncz-os/cix-installer/-/releases/permalink/latest).

## What's in 26.10
- **Desktop:** the Singularity desktop (labwc/wlroots, native Wayland) in the Cygnus theme (magenta and cyan on violet-black), with a first-login tour of the desktop, wallpapers, artist packs and the screensavers.
- **Window buttons:** every window has minimize, maximize and close buttons by default, system-wide.
- **Screensavers:** NCZ Screensavers 0.8.15 with the 0.3.22 settings plugin, 74 savers including the Black Hole (the default, in the Cygnus palette), Magmasimplex and Fractasia, with performance tiers per GPU.
- **Lock screen over a live screensaver:** the saver and the lock start together after 5 minutes idle. Behind the lock the saver keeps animating at 8 fps and half resolution, freezes on its current frame only when the password prompt appears (first key press, click or pointer movement), and starts again if the prompt is left to time out. A thermal guard pauses it while the machine is hot.
- **Login screen matches the lock screen** (greetd with the native Singularity greeter), at the panel's native resolution on T2 MacBooks.
- **Browsers:** Vivaldi 8.2 and Google Chrome 155 on both architectures (Vivaldi is the default on amd64); on Sky1, Chromium NCZ Sky1 Edition (default) decodes H.264, VP9 and AV1 web video on the VPU.
- **Wallpapers:** Artist Packs (NCZ, Cygnus, Alex Jay Brady, Brandon Perlow, Singularity) 1.2, rotating every 10 minutes, plus Bing and OCS online sources.
- **Sky1:** Linux 7.3.0-rc7 with the CIX GPU, VPU, NPU and audio drivers; Mali is the default GPU driver, Panthor an experimental boot entry; the NPU embedding server installs on demand.
- **Apple T2 Macs:** a kernel with Apple T2 support, tested on MacBookPro16,1, with a CPU package power cap ([`docs/T2-POWER-CAP.md`](../T2-POWER-CAP.md)), the T2 fan/SMC drivers, and Apple firmware and audio configuration fetched at first boot. The lock-screen saver pauses at 98 °C, 2 °C under the CPU's own limit, and resumes at 93 °C.
- **Rescue and recovery:** a rescue boot entry on the same kernel, a rescue partition whose wired ports use DHCP, and a live recovery container that generates its own SSH host keys per device. No SSH keys are preinstalled; `~/.ssh/authorized_keys` is left to you.
- **Agent stack:** `ncz install mnemos` (the MNEMOS memory server from the `mnemos-enterprise` container, offline-first), `ncz install zoder` and `ncz agent install <name>` set up MNEMOS, zoder and the agent runtimes end to end; nothing agentic is installed or started by default ([`docs/NCZ-AGENT-STACK.md`](../NCZ-AGENT-STACK.md)).
- **Boot menu:** rEFInd, with a rescue entry kept alongside the default.
- **One kernel per image:** the default, installer and rescue entries all boot the same 7.3.0-rc7 kernel ([`docs/ONE-KERNEL.md`](../ONE-KERNEL.md)).

## Changes since Preview 1
- Minimize and maximize buttons are the system-wide default for every window.
- NCZ Screensavers 0.8.15 and settings plugin 0.3.22: the *Screensaver and Lock* settings page is filled in on first open, and the screensaver starts behind the lock screen at the default idle timing. The saver keeps animating behind the lock until the password prompt appears and starts again when the prompt times out. A second lock request hands over to the running lock screen instead of replacing it, and locking before suspend follows the *lock on suspend* setting.
- Apple T2 MacBooks: the lock-screen saver heat limit is 98 °C, so the saver keeps animating in normal use; the login screen uses the panel's native 3072x1920 mode, matching the desktop session; the first-login tour starts 30 seconds after login and runs under a CPU quota, so the first minutes after login stay cool.
- Sky1: the dock and panels keep their surfaces mapped across a Mali buffer release (`gtk4-layer-shell` 1.3.0-1+ncz20261013), so the desktop session starts cleanly at login.
- Lock screen frame source: steadier saver frames behind the lock on AMD GPUs.
- Nearby sharing: the service keeps a steady memory footprint while peers reconnect.
- Browsers: Vivaldi 8.2.4133.84 and Google Chrome 155.0.8059.79.
- Wallpapers: the Artist Pack packages are version 1.2 and build reproducibly.
- First-login tour: a Sky1-only slide about hardware video decoding in Chromium NCZ Sky1 Edition.
- Installer: USB-serial adapters are not mistaken for braille displays, and the installer banner with the diagnostics login is shown once on every console, including the Sky1 serial console.
- Rescue and recovery: the rescue system configures wired ports with DHCP; the recovery container generates its own SSH host keys and machine-id on each device.
- SSH: no keys are preinstalled; `~/.ssh/authorized_keys` is left to you.
- `ncz`: the MNEMOS, zoder and agent installs work end to end, and `ncz status` reports them.

## Supported GPUs and hardware
NCZ-OS 26.10 ships drivers for **AMD, NVIDIA and Intel GPUs on amd64**, **Arm Mali on CIX Sky1 (vendor Mali stack by default, open Panthor driver also available)**, and the **CIX Sky1 NPU and VPU**. Machines we ran 26.10 on:

| Machine | CPU | GPU (driver) | Tested |
|---|---|---|---|
| MacBookPro16,1 (two units) | Core i9-9980HK, Core i7-9750H | AMD Radeon Pro 5300M/5500M class (Navi 14, `amdgpu`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| ASUS ROG GU502LV laptop | Core i7-10750H | NVIDIA GeForce RTX 2060 Mobile (proprietary `nvidia`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| HP OmniDesk desktop | Core Ultra 7 265 | Intel integrated graphics (Xe-LPG, `i915`) | Installed, boots to desktop |
| Dell Inspiron 5521 (2013) | Core i7-3537U | Intel HD Graphics 4000 (`i915`) | Installed, runs the desktop |
| Mac mini 2011 (Macmini5,1) | Core i5-2415M | Intel HD Graphics 3000 (`i915`) | Installed, desktop works (hardware-accelerated graphics) |
| Radxa Orion O6N | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| Minisforum MS-R1 | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| Radxa Orion O6 | CIX P1 (Sky1) | Arm Mali (vendor Mali) + NPU + VPU | Desktop, applications and display mode switching confirmed by a community tester |

Other GPUs and boards are untested. Video and audio playback and VPU hardware video decode were verified on the Sky1 boards; hardware video decode on other GPUs depends on the driver. Heavy screensavers are best on a stronger GPU.

## Installing
**Easy way (Linux or macOS; needs `zstd`):**
1. Download [`ncz-join-image.sh`](../../tools/ncz-join-image.sh) and, for your architecture, all the `…img.zst.part-*` files, `PARTS-<arch>.sha256` and `SHA256SUMS-<arch>` (the `amd64/` or `arm64/` folder on GitLab) into one folder. (GitHub limits each file to 2 GiB, so each image is split.)
2. Run `sh ncz-join-image.sh amd64` (or `arm64`). It checks every part, joins and unpacks them, and checks the finished image. It never writes to a disk.
3. Write the resulting `.img` to a USB drive of at least 16 GB (this erases the drive), then boot it and follow the installer. NCZ-OS installs from a USB drive only: an image written to an internal NVMe, SD card or eMMC is not supported (reliable media detection, and the disk the board booted from is never the one that gets erased). Balena Etcher works on any OS; on Linux you can use `dd` (see the [README quick start](../../README.md#quick-start-install-on-hardware)).

**By hand:**
1. Check the parts: `sha256sum -c PARTS-amd64.sha256` (or `PARTS-arm64.sha256`).
2. Join and unpack, for example for amd64: `cat ncz-os-amd64-20261014-4d0daef8.img.zst.part-* | zstd -d -o ncz-os-amd64-20261014-4d0daef8.img`
3. Check the image against `SHA256SUMS-amd64`: `sha256sum ncz-os-amd64-20261014-4d0daef8.img`

The amd64 image is 7.3 GB unpacked (about 5.8 GB compressed), the arm64 image 7.2 GB (about 5.4 GB compressed). Windows: use WSL, or unpack the parts with 7-Zip on the joined `.zst` file.

**Diagnostics login (installer only):** while the installer runs, its boot banner shows `diagnostics login: root / rescue` on every console, for SSH, telnet and Alt+F3 from your LAN; it is gone once the installed system boots. Set your own with `ncz_diag_pw=<pw>` or turn it off with `ncz_diag=0` on the installer's kernel command line ([`docs/RECOVERY-LOGINS.md`](../RECOVERY-LOGINS.md)).
