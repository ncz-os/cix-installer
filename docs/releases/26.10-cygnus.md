This is the versioned record of the 26.10 identity decision. Sections 2, 3 and
5 are the pre-release planning record from 2026-09-30 and are kept as written;
for what actually shipped, read the [26.10 release notes](26.10-cygnus-20261013.md). The naming rules come from the 2026-05-06 brand hierarchy:

- A codename is one clean word.
- Catalog identifiers and backstory go in the release notes as referents.
- Origin stories are never invented. If a name was picked on feel, the notes say so.

## 1. The name

**Cygnus.** It has three referents, and the release notes name all three.

1. **The constellation Cygnus, the Swan.** It is a northern constellation that
   lies along the band of the Milky Way. Its brightest star, Deneb, is one
   corner of the Summer Triangle. Its main stars also form the asterism known
   as the Northern Cross.
2. **Cygnus X-1.** This X-ray source in the constellation was found in 1964
   by rocket-borne X-ray detectors. It was the first object widely accepted
   as a black hole. It is a binary: a stellar-mass black hole on a
   5.6-day orbit with a blue supergiant companion (HDE 226868), whose gas it
   pulls into an accretion disk that glows in X-rays. A 2021 study put it
   about 7,200 light-years away and at roughly 21 solar masses. It is also
   the subject of the 1974 wager between Kip Thorne and Stephen Hawking,
   which Hawking conceded in 1990.
3. **The film.** The name also nods to the spaceship *Cygnus* in Walt Disney
   Productions' 1979 film *The Black Hole*. That is the same film that gave
   NCZ-OS its first codename, Reinhardt (26.5), and later Maximilian (26.7).
   We say this plainly because it is true: the operator chose the name with
   the film in mind ("Cygnus. Also goes with the movie").

**What we do not use.** Nothing from the film appears in NCZ-OS 26.10: no
artwork, ship designs, characters, logos, stills or music. Every image in the
Cygnus theme, the wallpapers, the boot art and the showcase is original. The
images come from our own Black Hole screensaver engine or are drawn by our own
scripts. If a ship is ever drawn, it will be an original design.

### Backstory paragraph (for the release notes)

> **Why "Cygnus"?** Look up on a summer night in the northern hemisphere and
> the Swan is flying down the Milky Way, with Deneb at its tail. Near the
> Swan's neck is Cygnus X-1, an X-ray source found by a sounding rocket in
> 1964. A decade later it became the first object most astronomers were
> willing to call a black hole. It is a stellar-mass black hole about 21
> times the mass of the Sun, pulling gas off a blue supergiant companion
> every 5.6 days, about 7,200 light-years away. Kip Thorne and Stephen
> Hawking bet on whether it really was a black hole (Hawking bet against,
> and conceded in 1990). NCZ-OS has always had a soft spot for black holes:
> our first codename, Reinhardt, came from Disney's 1979 film *The Black
> Hole*, whose ship is also called *Cygnus*. This time the name has a real
> sky behind it as well. The black hole on your screen is not a photograph
> and not a film still: it is rendered live by the NCZ-OS Black Hole
> screensaver, and the 26.10 wallpapers are frames from that same engine.

## 2. Version bump procedure

The version is set by hand at build time, and the bump is **not
retroactive**. Images that are already built keep their names. The first
image built after this change is the first 26.10 image.

> **Correction to the brief.** The brief names `build/build-iso.sh`, but that
> script is marked `STALE / ABANDONED - DO NOT USE` (its line 2). The current
> paths are `make image` (raw-GPT image for both architectures, through
> `build/build-installer-image.sh`) and the legacy arm64 d-i path
> `build/build-iso-di.sh --version`. Both read the identity from
> `release.conf`. (The legacy d-i ISO path has since been removed; `make
> image` / `build/build-image.sh` is the only build path.)

### 2.1 Identity (one commit, before the first 26.10 build)

`release.conf` is the single source for the product name, version and
codename. `post-install/50-brand.sh` writes these into `/etc/os-release`
(`VERSION_ID`, `VERSION_CODENAME=cygnus`, `PRETTY_NAME`), `/etc/lsb-release`
and `/etc/issue`. The d-i path also writes them into `.disk/info`, the GRUB
titles and the rEFInd info entry.

```sh
# on the release branch, in a worktree
sed -i 's/^NCZ_RELEASE_VERSION=.*/NCZ_RELEASE_VERSION="26.10"/; s/^NCZ_RELEASE_CODENAME=.*/NCZ_RELEASE_CODENAME="Cygnus"/' release.conf
git -C "$(git rev-parse --show-toplevel)" diff release.conf
```

Some places still hardcode the 26.7 name, and `release.conf` does not reach
them. The identity commit on this branch fixes the ones that change behavior
(see §2.4). Comments and history documents keep "Maximilian" where they
describe 26.7.

### 2.2 Build with the r-counter

`<n>` is the release counter. It is a manual argument, and it goes up by one
for every image that is handed out.

```sh
# raw-GPT image (both arches). VERSION on the make command line overrides the
# Makefile's date default; BUILD_VERSION becomes 26.10-r<n>-<sha>.
make image ARCH=arm64 VERSION=26.10-r<n>
make image ARCH=amd64 VERSION=26.10-r<n>
```

The legacy arm64 d-i ISO path (`build/build-iso-di.sh`) that this record also
listed has since been removed.

### 2.3 Tag the commit that was built, then push

```sh
ROOT="$(git rev-parse --show-toplevel)"
BUILT=<the exact commit the image was built from>   # the -<sha> part of BUILD_VERSION
git -C "$ROOT" tag -a v26.10-r<n> "$BUILT" -m "NCZ-OS 26.10 Cygnus r<n>: <image names + sha256>"
git -C "$ROOT" push gitlab  v26.10-r<n>
```

Tags follow the historical form `v<version>-r<n>` (`v26.6-r113` through
`v26.7-r198`). **Decision needed: the r-counter.** One option continues the
global counter from the last r-tag, so the first 26.10 image would be
`v26.10-r199`. The other restarts it at `r1` for each version line. The
history so far uses one global counter.

### 2.4 What the identity commit on this branch changes

| File | Change |
|---|---|
| `release.conf` | `26.7` / `Maximilian` becomes `26.10` / `Cygnus` |
| `build/build-iso-di.sh` (since removed) | The ISO volume label was hardcoded as `NCZ_MAXIMILIAN`. It is now built from `release.conf` as `NCZ_CYGNUS`. The film quote addressed to the codename ("Now, Maximilian, calm down...") is replaced with a neutral line, because it only makes sense for the robot's name. |

Test fixtures that feed `26.7`/`Maximilian` as sample input
(`build/test-ncz-ui.sh`, `build/test-installed-target-verifier.sh`) are
self-contained, so they are left as they are.
