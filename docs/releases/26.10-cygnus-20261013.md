# NCZ-OS 26.10 "Cygnus" — 2026-10-13 images

NCZ-OS 26.10 "Cygnus" is a Debian-based desktop OS for **CIX Sky1 boards (arm64)** and **Intel/AMD PCs and Apple T2 Macs (amd64)**. Each image is a raw GPT disk image: write it to a drive of at least 16 GB (this erases the drive), boot it and follow the installer.

These images replace the 26.10 Preview 1 images of 2026-10-12 ([notes](26.10-cygnus-preview1.md)). Both are built on the Linux 7.3.0-rc7 kernel, a release candidate. Back up anything you care about.

**Download:** the images are published on the project's [latest release](https://github.com/ncz-os/cix-installer/releases/latest) page.

|---|---|---|---|

See [Supported GPUs and hardware](#supported-gpus-and-hardware) below for the machines we ran 26.10 on.

## What's in 26.10
- **Desktop:** the Singularity desktop in the Cygnus theme (magenta and cyan on violet-black), with a first-login tour of the desktop, wallpapers, artist packs and the screensavers.
- **Window buttons:** every window has minimize, maximize and close buttons by default, system-wide.
- **Lock screen over a live screensaver:** the lock screen sits on top of the running screensaver and does not ask for a password until you touch the keyboard or mouse. Behind the lock the saver runs at 8 fps at half resolution and freezes after 15 seconds to keep the machine cool.
- **Login screen matches the lock screen** (layout, spacing, field labels).
- **Screensavers:** NCZ Screensavers 0.8.13 with the 0.3.21 settings plugin, 74 savers including the Black Hole, Magmasimplex and Fractasia showpieces, with performance tiers per GPU.
- **Sky1:** Linux 7.3.0-rc7 with the CIX GPU, VPU, NPU and audio drivers; Mali is the default GPU driver, Panthor an experimental boot entry. Chromium NCZ Sky1 Edition decodes H.264, VP9 and AV1 web video on the VPU.
- **Apple T2 Macs:** a kernel with Apple T2 support, tested on MacBookPro16,1, with a CPU package power cap and Apple firmware and audio configuration fetched at first boot.
- **Agent stack:** `ncz install mnemos`, `ncz install zoder` and `ncz agent install <name>` set up MNEMOS, zoder and the agent runtimes end to end; nothing agentic is installed or started by default ([`docs/NCZ-AGENT-STACK.md`](../NCZ-AGENT-STACK.md)).
- **Boot menu:** rEFInd, with a rescue entry kept alongside the default.
- **One kernel per image:** the default, installer and rescue entries all boot the same 7.3.0-rc7 kernel ([`docs/ONE-KERNEL.md`](../ONE-KERNEL.md)).

## Changes since Preview 1
- Minimize and maximize buttons are the system-wide default for every window.
- NCZ Screensavers 0.8.13 and settings plugin 0.3.21: the *Screensaver and Lock* settings page is filled in on first open, and the screensaver starts behind the lock screen at the default idle timing. A second lock request now hands over to the running lock screen instead of replacing it.
- Sky1: the dock and panels keep their surfaces mapped across a Mali buffer release (`gtk4-layer-shell` 1.3.0-1+ncz20261013), so the desktop session starts cleanly at login.
- Lock screen frame source: steadier saver frames behind the lock on AMD GPUs.
- Apple T2 MacBooks: the login screen uses the panel's native 3072x1920 mode, matching the desktop session; the first-login tour starts 30 seconds after login and runs under a CPU quota, so the first minutes after login stay cool.
- First-login tour: a Sky1-only slide about hardware video decoding in Chromium NCZ Sky1 Edition.
- Installer: USB-serial adapters are not mistaken for braille displays, and the installer banner is shown once.
- Rescue and recovery: the rescue system configures wired ports with DHCP; the recovery container generates its own SSH host keys and machine-id on each device.
- SSH: no keys are preinstalled; `~/.ssh/authorized_keys` is left to you.
- `ncz`: the MNEMOS, zoder and agent installs work end to end, and `ncz status` reports them.

## Supported GPUs and hardware
NCZ-OS 26.10 ships drivers for **AMD, NVIDIA and Intel GPUs on amd64**, **Arm Mali on CIX Sky1 (vendor Mali stack by default, open Panthor driver also available)**, and the **CIX Sky1 NPU and VPU**. Machines we ran 26.10 on:

| Machine | CPU | GPU (driver) | Tested |
|---|---|---|---|
| Radxa Orion O6N | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| Minisforum MS-R1 | CIX P1 (Sky1) | Arm Mali (vendor Mali; Panthor available) + NPU + VPU | Installed, desktop, video (VPU hardware decode) and audio playback |
| Radxa Orion O6 | CIX P1 (Sky1) | Arm Mali (vendor Mali) + NPU + VPU | Desktop, applications and display mode switching confirmed by a community tester (installed from an earlier release and updated with the fixed desktop library) |
| MacBookPro16,1 (two units) | Core i9-9980HK, Core i7-9750H | AMD Radeon Pro 5300M/5500M class (Navi 14, `amdgpu`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| ASUS ROG GU502LV laptop | Core i7-10750H | NVIDIA GeForce RTX 2060 Mobile (proprietary `nvidia`) + Intel UHD 630 (`i915`) | Installed, boots to desktop |
| HP OmniDesk desktop | Core Ultra 7 265 | Intel integrated graphics (Xe-LPG, `i915`) | Installed, boots to desktop |
| Dell Inspiron 5521 (2013) | Core i7-3537U | Intel HD Graphics 4000 (`i915`) | Installed, runs the desktop |
| Mac mini 2011 (Macmini5,1) | Core i5-2415M | Intel HD Graphics 3000 (`i915`) | Installed, desktop works (hardware-accelerated graphics) |

Other GPUs and boards are untested. Video and audio playback and VPU hardware video decode were verified on the Sky1 boards; hardware video decode on other GPUs depends on the driver. Heavy screensavers are best on a stronger GPU.

## Installing
**Easy way (Linux or macOS; needs `zstd`):**
1. Download [`ncz-join-image.sh`](../../tools/ncz-join-image.sh), `SHA256SUMS`, `PARTS.sha256` and all the `…img.zst.part-*` files for your architecture into one folder. (GitHub limits each file to 2 GiB, so each image is split.)
2. Run `sh ncz-join-image.sh arm64` (or `amd64`). It checks every part, joins and unpacks them, and checks the finished image. It never writes to a disk.
3. Write the resulting `.img` to a USB drive of at least 16 GB (this erases the drive), then boot it and follow the installer. NCZ-OS installs from a USB drive only: an image written to an internal NVMe, SD card or eMMC is not supported (reliable media detection, and the disk the board booted from is never the one that gets erased). Balena Etcher works on any OS; on Linux you can use `dd` (see the [README quick start](../../README.md#quick-start-install-on-hardware)).

**By hand:**
1. Check the parts: `sha256sum -c PARTS.sha256` (files you did not download report as missing; that is fine).
2. Join and unpack, for example for arm64: `cat ncz-os-arm64-20261013-d395bb2d.img.zst.part-* | zstd -d -o ncz-os-arm64-20261013-d395bb2d.img`
3. Check the image against `SHA256SUMS`: `sha256sum ncz-os-arm64-20261013-d395bb2d.img`

Each image is 7.6 GB unpacked (about 5.7 GB compressed for arm64, 6.1 GB for amd64). Windows: use WSL, or unpack the parts with 7-Zip on the joined `.zst` file.
