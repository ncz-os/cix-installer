## Design notes (check semantics)

- **`required-optional` is scoped to staged-deb rows.** The NCZ_LOCAL_DEBS
  `optional`/`required` flag describes optionality of *staging the .deb
  into the desktop mirror*, not component necessity. Example:
  `ncz-singularity-desktop` has an arm64 ncz-apt row with `required=yes`
  (20-desktop.sh hard-fails without it) while its two pool rows are
  `optional` to stage (the apt path is primary on arm64). That is not
  drift. A pool row whose required flag contradicts the mirror flag IS
  drift.
- **`seed-published` reads the published set offline** from the item AC
  report (`~/Projects/oc-apt-publish/report.md`, override
  `NCZ_APT_PUBLISH_REPORT`). When the file is absent the check degrades to
  a stderr note and skips this category.
