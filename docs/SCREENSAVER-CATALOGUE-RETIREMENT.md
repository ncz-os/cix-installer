# Legacy screensaver chooser retired — the package catalogue is the only one

**Date:** 2026-10-05
**Scope:** `post-install/58-screensaver-chooser.sh` and `assets/screensaver-chooser/`
(release-notes open question 4).

## What changed

The image used to expose *two* screensaver catalogues: a legacy one shipped and
built by this repo, and the one shipped inside the `ncz-screensavers` package
that `post-install/59-ncz-screensavers-pkg.sh` installs. Only the package
catalogue may ship.

Retired:

* `post-install/58-screensaver-chooser.sh` — built the legacy Vala picker from
  `assets/screensaver-chooser/` and installed the legacy 84-row
  `/usr/share/ncz-screensaver-chooser/hacks.tsv`.
* `assets/screensaver-chooser/` — the whole legacy chooser tree: `hacks.tsv`
  (84 rows), the Vala plugin source, `ncz-screensaver-run`, `ncz-idle-manager`,
  the `dev.ncz.screensaver` schema copy, the previews and the meson project.

Every reference was removed with them: `post-install/hooks.list.*`
(regenerated by `build/gen-hooks-lists.sh`), `post-install/run-all.sh`
(`MACHINE_HOOKS_RE` and `_SKIP_DESKTOP_RE`), `build/build-squashfs-layers.sh`
(asset stamp, staging copy, baked-hook loop, asset allowlist),
`build/build-baked-rootfs.sh` (bake hooks, staged assets),
`manifests/desktop.pkgs`, `docs/platform-inventory.tsv`,
`docs/PLATFORM-SPLIT-DESIGN.md`, and the `59` header comment.

## What replaces it

`post-install/59-ncz-screensavers-pkg.sh` installs the `ncz-screensavers` and
`ncz-screensavers-plugin` packages from the offline mirror. They own the engine
(`/usr/bin/ncz-screensaver`), the idle timer
(`/usr/libexec/ncz-screensaver-idled`), the 74-title catalogue
(`/usr/share/ncz-screensavers/hacks.tsv`) and the Singularity Settings plugin
(`/opt/singularity/lib/singularity/plugins/screensaver/{libscreensaver.so,screensaver.plugin}`).
`post-install/62-cygnus-screensaver-default.sh` keeps setting the black-hole
Cygnus default through a GSettings override on the package-owned schema; it was
never coupled to hook 58.

`build/verify-installed-target.sh` already asserts the package world and never
the legacy paths: it requires `/usr/share/ncz-screensavers/hacks.tsv`, the
`screensaver` folder inside `/opt/singularity/lib/singularity/plugins/`, the
`ncz-screensavers-plugin` package, `>= 84` `*_gles3` hack binaries, and that
`ncz-idle-manager.service` is **not** enabled next to the package's
`ncz-screensaver-idled.service`. `build/test-installed-target-verifier.sh`
exercises those gates.

## Verification

* `bash build/gen-hooks-lists.sh --check` — lists current after the removal.
* `bash build/lint-platform.sh` and `bash build/test-platform-lint.sh` — the
  inventory, hook-list and file-coverage checks stay green.
* `bash build/test-installed-target-verifier.sh` — the installed-target gates
  above pass and no legacy path is expected.
